## 💡 Como rodar os exercícios

1. Certifique-se de ter o **Python 3** instalado (`python3 --version`).
2. Crie uma pasta para cada exercício ou trabalhe em arquivos separados (ex.: `smartphone.py` e `main.py`).
3. Execute pelo terminal:

```bash
python3 main.py
```
